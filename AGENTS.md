# Repository guidance

- Do not use em dashes in responses or drafted text.
- This is a local research POC. Keep tenant checks on every private API operation.
- Never label simulated metrics as measured or claim formal privacy guarantees.
- Keep datasets, model weights, adapters, and session state in ignored local storage.
- Run `npm run build` and `.venv/bin/python -m pytest tests -q` before a PR.
